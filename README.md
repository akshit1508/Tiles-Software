# Tile Management System

A web-based management application for a tile business.

## Stack

Frontend:
Next.js + TypeScript

Backend:
NestJS + TypeScript

Database:
MongoDB

Production Database:
MongoDB Atlas

## Core Features

- Product management
- Inventory management
- Customer management
- Order management
- Payment tracking
- Outstanding tracking
- Sales
- Reports

## Development

The project contains separate frontend and backend applications.

apps/web → Next.js

apps/api → NestJS
